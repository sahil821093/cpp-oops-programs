# 💻 C++ Object-Oriented Programming (OOPs)

A collection of clean C++ programs demonstrating core Object-Oriented Programming concepts.

## 📂 Programs Included
1. **`01_student_class.cpp`** – Classes, Objects, Encapsulation, and Constructors.
2. **`02_inheritance_employee.cpp`** – Single Inheritance (`Person` → `Employee`) and `protected` access specifier.
3. **`03_operator_overloading.cpp`** – Binary Operator Overloading (`+`) for adding complex numbers.

## 🛠️ Tech Stack
- **Language:** C++
- **IDE:** Dev-C++ / VS Code
